# Идея проекта

Бот-напоминалка: присылает список дел на завтра в 20:00.

![Схема бота](img/skhema.png)

| Что храним | Пример | Откуда берём |
|---|---|---|
| дело | «сдать доклад» | пишет пользователь |
| дата | 30.10 | пишет пользователь |
| время напоминания | 20:00 | настройка, по умолчанию |
